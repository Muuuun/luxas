# AAAI

> Official author guidelines: https://aaai.org/conference/aaai/aaai-26/aaai-26-call-for-papers/

## Article Types

| Type | Page Limit | Camera-Ready Extra | Notes |
|------|-----------|-------------------|-------|
| **Main conference paper** | 7 pages | +1 page | Excludes refs |

## Formatting

### Page / Layout
- Two-column layout per `aaai2026.sty`
- **Strict style file adherence** — AAAI is known for strict formatting checks

### Template
- **aaai2026.sty** — mandatory, strictly enforced

### Abstract
- No strict word limit; keep concise

## References & Citations
- AAAI citation style (numbered)

## Required Sections
- **Blind review** — double-blind
- References do not count toward page limit

## Common Pitfalls
- Exceeding 7-page limit (strictest among ML venues)
- Not using the exact AAAI template version for the current year
- Style file violations caught by automated checks
