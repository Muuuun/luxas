## Not Listed?

1. Check the publisher-level file for base rules
2. Fetch the official author guidelines URL (usually at the journal homepage under "For Authors" or "Submit")
3. Use the search skill: `search web "[journal name] author guidelines [year]"`
4. Apply the universal checklist from `CHECKLIST.md`
