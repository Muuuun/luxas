# eLife

> Official author guidelines: https://elife-rp.msubmit.net/html/elife_author_instructions.html

## Article Types

| Type | Word Limit | Display Items | Notes |
|------|-----------|---------------|-------|
| **Research Article** | No strict limit | No strict limit | Peer-reviewed |
| **Short Report** | ~1,500 words main text | Up to 3 | Brief findings |
| **Tools and Resources** | No strict limit | No strict limit | Methods/tools |
| **Research Advance** | ~1,500 words | Up to 3 | Follow-up to previous eLife paper |

## Formatting

### Title
- Concise; no abbreviations unless standard

### Abstract
- Max **150 words**
- Unstructured single paragraph

### eLife Digest
- **Required** — unique to eLife
- ~300 words, written in plain language for non-scientists
- No jargon, no citations
- Explain: What was the problem? What did you do? What did you find? Why does it matter?

### Impact Statement
- **1 sentence**, max ~200 characters
- Summarizes the significance

### Manuscript Format
- Word, LaTeX, or PDF accepted
- eLife has its own LaTeX template

## Figures & Tables

### Resolution
- **300 DPI** minimum; higher for line art

### Formats
- TIFF, EPS, PDF, PNG, JPG
- Vector preferred for graphs

### Figure Supplements
- eLife uses "Figure supplements" (e.g., Figure 1—figure supplement 1)
- No limit on figure supplements
- Each must be referenced from the parent figure

### Source Data
- Raw data files can be attached to individual figures as "source data"

## References & Citations

### In-text Style
- Author-date style: (Smith et al., 2024)
- Harvard format

### Reference List Format
- Alphabetical order by first author
- All authors listed (no "et al." cutoff in reference list)
- Include article titles, DOIs
- eLife reference style

## Required Sections
- **eLife Digest** — mandatory plain-language summary
- **Impact Statement** — 1 sentence
- **Data Availability Statement**
- **Author Contributions** — CRediT taxonomy
- **Competing Interests**
- **Ethics** — if applicable
- **Funding** — table format (Funder, Grant ref, Author)

## Special Features
- **Open access** (CC-BY license)
- **Reviewed Preprints** — eLife publishes reviews alongside preprints
- **Transparent review** — reviews and author responses published
- No accept/reject; all reviewed papers published with assessment
- **Figure supplements** and **source data** as first-class citizens

## Templates
- eLife LaTeX template available on GitHub and Overleaf

## Common Pitfalls
- Missing eLife Digest (unique requirement)
- eLife Digest written too technically (must be plain language)
- Not understanding eLife's publish-then-review model
- Not providing source data for figures
