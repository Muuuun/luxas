# Nature

> Official author guidelines: https://www.nature.com/nature/for-authors/formatting-guide

## Article Types

| Type | Main Text Word Limit | Display Items | References | Notes |
|------|---------------------|---------------|------------|-------|
| **Article (6-page)** | ~2,500 words | Up to 6 (figures + tables) | Up to 50 | Excludes Methods, refs, legends |
| **Article (8-page)** | ~4,300 words | Up to 6 | Up to 50 | Excludes Methods, refs, legends |
| **Brief Communication** | ~2,000 words (incl. abstract, refs, legends) | Up to 2 | ~20 | No headings in main text |
| **Matters Arising** | ≤1,200 words | 1–2 small | Few | Must relate to Nature paper within 18 months |
| **Review / Perspective** | By arrangement | By arrangement | By arrangement | Invited |

## Formatting

### Title
- **Max 10 words** (or ~90 characters)
- No jargon or abbreviations unless widely known

### Abstract ("Bold First Paragraph")
- **~150 words** (up to 300 at editor's discretion)
- Unstructured single paragraph, set in bold in print
- **No references** in abstract
- Content: general intro → brief non-technical summary of results → implications

### Methods
- **~3,000 words** typical (can be longer if necessary)
- **Online-only** (not in print edition)
- Cannot contain figures or tables (use Extended Data)
- Must include **Data Availability** and **Code Availability** subsections
- Methods-only references are listed separately and do NOT count against the 50-ref main limit

### Font
- Body text: **12 pt Times New Roman**, double-spaced

## Figures & Tables

### Dimensions
| Width | Measurement |
|-------|------------|
| Single column | **89 mm** (3.5 in) |
| 1.5 column | 120–136 mm |
| Double column (full width) | **183 mm** (7.2 in) |
| Max height | 247 mm |

### Resolution
| Content | Minimum DPI |
|---------|------------|
| Line art / graphs | **1000+** (vector PDF/EPS preferred) |
| Photographs / micrographs | **300–600** |
| Mixed (line + photo) | **600** |

### Formats
- Preferred: **PDF, EPS** (vector for line art/graphs)
- Acceptable: TIFF (LZW compression), PNG (600+ DPI)
- Also: AI, layered PSD, PostScript

### Font in Figures
- **Sans-serif only** (Arial or Helvetica preferred)
- Panel labels (a, b, c): **8 pt, bold, lowercase**
- Axis/tick labels: **5–7 pt** (5 pt minimum)

### Color
- Submit in **RGB** (Nature converts to CMYK for print)
- Colorblind-accessible palettes recommended (blue-orange, viridis)

### Line Weights
- Min: **0.25 pt**; Max: **1 pt**

### Extended Data
- Up to **10 Extended Data** display items (online only, peer-reviewed)
- 180 mm wide × 170 mm tall
- Sans-serif 5–7 pt; 0.25–1 pt lines; RGB; max 300 ppi; max 10 MB each

## References & Citations

### In-text Style
- Superscript Arabic numerals in order of first appearance
- After a number in text, use parenthetical: (ref. 44), (refs. 55–60)

### Reference List Format
- ≤5 authors: list all; ≥6 authors: first author + "et al."
- Surname, Initials (no periods between initials)
- **Article titles included** (upright, sentence case)
- Journal names: italic, abbreviated
- Volume: **bold**
- Year in parentheses at end
- Example: `Eigler, D. M. & Schweizer, E. K. Positioning single atoms with a scanning tunnelling microscope. *Nature* **344**, 524–526 (1990).`

**Note**: BibTeX `.bib` files are NOT accepted for final submission; refs must be inline in `.tex`.

## Required Sections (in order)

1. Title
2. Authors + Affiliations
3. Bold first paragraph (abstract)
4. Main text (no prescribed headings; typically Intro–Results–Discussion)
5. Main references (up to 50)
6. Tables
7. Figure legends
8. Methods (incl. Data Availability + Code Availability)
9. Methods references (separate list)
10. Acknowledgements
11. Funding statement
12. **Author Contributions** — by initials for each co-author
13. **Competing Interests** — mandatory declaration for every author
14. Additional information
15. Extended Data figure/table legends

## Supplementary Information
- Peer-reviewed, online only
- Max **30 MB per file**; total max **150 MB**
- Preferably ≤10 files
- Preferred format: PDF
- Image resolution in SI: **150 DPI** acceptable
- Must include SI Guide file with title + ≤50-word summary per item

## Templates
- Nature LaTeX template: https://www.nature.com/documents/nature-template.zip
- Word template available
- Initial submission: single file (Word or PDF, up to 30 MB) with text + figures together

## Common Pitfalls
- References in the abstract (not allowed)
- Using "Scheme" numbering (Nature never uses it — use "Figure")
- Figures in Methods section (use Extended Data instead)
- Exceeding 150-word abstract / 10-word title
- Missing Data/Code Availability statements
- BibTeX .bib files in final submission (must be inline)
- Forgetting Extended Data display items count toward the 10-item limit
