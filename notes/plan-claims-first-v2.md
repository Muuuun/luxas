# Plan: claims-first v2 (debate-adjudicated, 2026-08-28)

*Input: `architecture-review-2026-08-28.md` §5 (nine gaps from the pp-vs-ss trace). Three independent positions were taken over the review, the design (`design-claims-first.md`), the anti-pattern rules in CLAUDE.md and the code: ENGINEER (cost to build, testability, blast radius), PI (scientific validity), COST SKEPTIC (dollars, hours, rituals). Positions are summarised in §1; the adjudication per gap is §2; the plan is §3; the A/B that decides the open points is §4.*

## 1. The three positions, compressed

**Engineer.** Found the actual bug behind gap 5.1: `claims-table.ts` compares producer↔blind pairs with `agreement()` only and never `relation()`, so the inputs-by-value comparability rule that protects producer↔producer pairs is skipped for exactly the pair that generates disputes. Fix that (~25 lines) and reject the `SUPERSEDED:` harness line (needs a "which experiment answered which id" detector = LLM judgment). Speed bump: non-blocking prefix on cosmetic spawns, ~20 lines. Batch finish: do not restructure the 31 early returns — append a cheap "also pending" trailer to the synthesis/plan branches, sliced off before escalation keying. Defer 5.3 (job ownership ≠ computation: `python -c "print(1.96)"` passes) and 5.5 (harness-written attestation from a yes/no is the self-certified independence the Draft-1 adjudication deleted). Headline cap as a write-time hint, never MALFORMED.

**PI.** Keep the blind estimates alive: E3's "45 ± 10" with `inputs: []` was the most useful line of the run — it bought E4. Rule: a replicator with empty inputs was *handed* the producer's input values, so record them on its behalf; never read empty inputs as "ignore". `SUPERSEDED` only from a discriminator with a locator, never from a producer re-run or a brain note. Cap the *obligation scope* (frame ids + ≤3 declared by load), not the declarations — hiding a declaration lets a producer route the load-bearing number into a slot nobody estimates. Attestations: closed questions with the two routes visible and a one-clause reason; **do not demote on a low yes-rate — a low rate is a finding about the experiments**. Blind estimates: grade by route named + assumed definition (observable/units/sign) stated + one number reproduced; missing the definition is what demotes. Insists on written definitions of *independent route* (different formalism or limiting approximation, not different library) and *anchor* (a value someone outside the project could have written down before the run), and that a toy estimate can flag and converge but never anchor.

**Cost skeptic.** Baseline $95.5/29 h: review machinery ~30% of tokens, illustration ~23% spent while the abstract was blocked, 17 replicators against 23 "headline" ids. Top three by savings: headline cap (≈$15–20, 3–4 h), cosmetic kill-switch (≈$12–20, 2–3 h), batch finish (≈$8–12, 3–5 h). `inputs: []` → incomparable as a one-liner that removes all three false disputes. Refuses: any new agent or per-pair LLM question, `SUPERSEDED` bookkeeping before the comparability rule is tried alone, a novelty×load allocator. Wants attestations *computed* (different inputs + different agent = independent), review iterations default 3 → 2, blind cap 1 as the next default. Settling experiments for everything: env-var on/off, compare `claims_dispatch` / `claims_compliance` counts.
